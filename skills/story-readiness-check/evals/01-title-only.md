# Eval 01 — title only

## Input
```
Is this story ready? "Customer can download the invoice as PDF"
```

## Must
- [ ] The answer asks for the description (who, what, why, rules) and stops there.
- [ ] It says in one line what it needs (requirements, existing AC, designs) — not a long questionnaire.

## Must not
- [ ] No inventory, AC, or verdict is produced from the title.
- [ ] No business rule is invented (format, retention, who may download).
